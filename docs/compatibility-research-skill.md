# Поиск и проверка совместимости серверной сборки

Алгоритм предназначен для произвольных пользовательских спецификаций, а не для одного демонстрационного списка.

## Входные строки

- Разбирай формат `артикул TAB описание TAB количество`; последнее отдельное число — число устанавливаемых единиц.
- Числа внутри описания являются характеристиками, а не количеством заказа.
- Передавай модели всю сборку целиком и сохраняй отдельный результат для каждой строки.

## Поиск

- Для каждой позиции сформируй два коротких запроса: точный артикул для поиска спецификации самого компонента и точная платформа вместе с артикулом компонента/составом сборки для проверки связи между ними.
- Выполняй оба запроса параллельно, а позиции — небольшими параллельными группами.
- Получай AI-сводку и выдержки страниц в ответе Tavily Search. После удаления дубликатов передавай максимум три релевантных страницы на позицию; отдельный этап Tavily Extract не используй.
- Передавай сводку как ориентир, а не как самостоятельное доказательство. Технические выводы должны ссылаться на реальные URL из выдержек.
- Отдавай предпочтение источникам производителя. При их отсутствии используй точные технические страницы дистрибьюторов, интеграторов и профессиональные источники; явно отмечай менее прямое подтверждение.

## Анализ и статусы

- Для каждой позиции проверь её критические характеристики и совместную установку с учётом количества, слотов, разъёмов, габаритов, питания и охлаждения по применимости.
- Неизвестную версию BIOS показывай как замечание по подготовке, а не как незакрытое обязательное условие. Блокером она становится только при найденном явном ограничении для модели CPU.
- «Совместимо» означает, что обязательные проверки закрыты источниками. Пониженная частота, число задействованных каналов и другие потери производительности могут быть рекомендациями, но сами по себе не делают сборку несовместимой.
- «Не совместимо» выдавай только при прямом документированном конфликте.
- «Не подтверждено» используй, когда источник не удалось прочитать или в первых трёх применимых источниках отсутствует конкретное необходимое сведение. Назови именно это сведение.
- Для DIMM считай модули на процессор и верхнюю частоту по CPU, модулю и платформе. Точные каналы и номера слотов указывай только при наличии схемы заполнения; иначе это рекомендация.
- Никогда не считай поисковое совпадение доказательством: проверь содержимое источника, точную модель и применимость. Не создавай источники, URL или цитаты.

## Проверка результата

- Каждая входная строка должна получить ровно один статус и короткую причину.
- Не объединяй одинаковые SKU, если это отдельные строки ведомости.
- Показывай рекомендации отдельно от причин несовместимости.
- Повторный запрос должен использовать кеш поиска и модели, если BOM и параметры запроса не изменились.
