# Сайт-визитка

Простой адаптивный сайт на HTML и CSS с тёмной темой. Без JavaScript, сторонних библиотек, внешних шрифтов и сборки.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не нужна.

Для запуска через локальный сервер, если установлен Python:

```sh
python -m http.server 8000
```

Откройте <http://localhost:8000>. Остановка сервера — `Ctrl+C`.

## Файлы

- `index.html` — содержимое страницы: знакомство, информация о себе и контакты.
- `styles.css` — тёмная тема, декоративная CSS-графика и адаптивная вёрстка.
- `.gitignore` — исключения для временных файлов, локальных настроек и секретов.

## Настройка под себя

Имя «Алексей», описание и адрес `hello@example.com` — демонстрационные данные. Перед публикацией:

1. Замените имя и тексты в `index.html`, включая `<title>` и описание в `<meta name="description">`.
2. Замените email в тексте и в обоих атрибутах `href="mailto:hello@example.com"`.
3. Измените интересы в списке `.tags`.
4. При необходимости настройте цвета в блоке `:root` файла `styles.css`.

На небольших экранах блоки перестраиваются в одну колонку. Предусмотрены фокус для клавиатуры, ссылка перехода к содержимому и поддержка настройки уменьшенного движения.

## Публикация

Разместите `index.html` и `styles.css` рядом на любом статическом хостинге. Сборка и серверная часть не требуются.
